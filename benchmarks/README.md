# Performance Evaluation

This directory contains benchmark source code.

Updated benchmark results will be added after
the final evaluation.

Evaluation categories:

- Vision detection accuracy
- Precision, recall and F1-score
- Mean average precision
- Vision inference latency
- Llama inference latency
- Time to first token
- Token generation speed
- Integrated processing latency
- Effective inspection rate
- System memory utilization
- Monitored PMIC rail power
- Energy consumption
- CPU temperature
- Offline operation
